# AS Physics Paper 2 (7407/2): guided-flashcard coverage, v430

## Purpose
The new Flashcards panel includes a separate **AQA AS Physics Paper 2** area for the distinct format of 7407/2. A normal mock requires knowledge of topics. This pack trains *how to start*, *how to interpret results*, and *how to reject plausible MCQ distractors*.

**Structure verified from AQA**: 90 minutes, 70 marks, Section A (20 practical/data marks), Section B (20 synoptic short/long-answer marks), Section C (30 one-mark multiple-choice questions). It covers AS topics 3.1–3.5, not A-level Physics 7408/2. This pack has **132 deliberately brief original cards**, not copied AQA questions or longer exam essays: **A39, B30, C63**. All 63 Section C cards show four choices and explain a common wrong route.

A "first step" button gives optional scaffolding. A trap explanation appears with the model answer. A dedicated A/B/C/mixed launch uses the normal weakness/due weighting and existing spaced-repetition history. A card previously mastered does not become a new card; XP, reviews, points and purchases keep existing keys. The ordinary Paper 2 skills also appear as labelled Physics flashcard topics. The original mixed school-mock card pool is unchanged (new IDs have `mock:false`).

## Formatting and marking quality gates
- Card front <= 175 characters; back <= 165, hint and common trap <= 145. Each question targets one short skill. Avoid converting full Section A/B essays into flashcards.
- Six AQA AS required practicals remain reviewable; data/uncertainty, graph choice, apparatus, waves, mechanics, electricity, particles, and most common MCQ scaling/sign traps are covered. Further source-specific styles can be added without rewriting existing cards.
- Section C A/B/C/D options are manually authored; exactly one is marked correct. Correct choice rotates by card ID, not always A. Wrong alternatives must never be awarded full marks because of fuzzy token matching.
- After reveal, the model answer is shown alongside the specific trap. Optional hints can be hidden, letting the same skill progress from support to independent recall.
- Separate A/B/C/mixed and 10/20/30/all sessions. Existing adaptive due/weakness weighting, review history, rewards and optional cloud sync retained.
- Test the real loaded bank, answer grader and narrow phone layouts. Do not release to production until PR checks pass and a READY preview has been verified.
