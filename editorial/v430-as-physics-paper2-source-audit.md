# AQA AS Physics Paper 2 (7407/2): short coaching-card source audit

**Scope:** the AS qualification, not A-level 7408/2. AQA specifies **70 marks in 90 minutes**: **20 marks practical skills/data analysis (A)**, **20 marks synoptic longer questions (B)**, **30 one-mark MCQs (C)**. Sections assess the AS core: measurements, particles/radiation, waves, mechanics/materials, electricity.

## Study design and progression

Use the dedicated buttons in **Flashcards**: start with **A · Practicals**, then **B · Reasoning**, then **C · MCQ**, and finally **All Paper 2 styles**. Each question is short enough to answer from memory. Open the hint only if needed, check the answer, read the method/trap, and use Again/Hard/Good/Easy to save a spaced-review rating. The 20 interactive MCQs use four options and exact A–D marking. The other rapid cards intentionally train one underlying judgement at a time.

The normal mock mode **does not** include these coaching-only cards. A full paper still contains real data tables, diagram interpretation and multi-stage questions; coaching cards cannot replace that exam simulation. Never alter saved IDs or existing progress storage keys.
